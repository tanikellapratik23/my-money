# My Money
Your personal money manager: monthly income, expenses, category budgets, savings, emergency fund, Roth IRA, brokerage allocations, credit cards, subscriptions, and goals.

## Run
Open index.html or serve this repository with any static web server. No build step or dependencies.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Your data
Entries save in this browser on this device, not in this repository. Export a JSON backup in Backup & settings before clearing browser data or switching devices. Anyone with access to the same browser profile can view local entries. No bank connection or automatic sync.

Subscriptions carry forward; annual subscriptions are divided by 12 for monthly planning. Do not also log them as expenses. Credit card balances are tracked separately to avoid counting purchases twice. Goal balances are updated manually, separately from monthly savings allocations. Each new month starts its own income, expenses, and allocations; prior records remain in History.
